# 어게인 아트 (Again Art)

**미술대학생 작품 마켓플레이스** — 졸업 전시가 끝나면 창고에 쌓이거나 폐기되던
회화·일러스트·판화·조소 작품을 갤러리·카페·사무실·개인에게 **구매 또는 대여**로 다시 잇는
데모 서비스입니다.

> English: [README.md](./README.md)

**라이브 데모: https://clsoftlab-lang.github.io/art-student-marketplace/**

빌드 없음, 의존성 없음, 바이너리 없음. 화면의 모든 작품은 시드값으로부터 **인라인 SVG로
즉석 생성**되므로 이미지 파일 하나 없이도 갤러리가 가득 차 보입니다.

## ⚠️ 데모 모드 경계 (먼저 읽어주세요)

이 저장소는 **프런트엔드 데모**입니다. 쉽게 말해:

- **모든 작품과 작가는 가상입니다.** 각 "작품"은 실제 스캔이 아니라 **절차적으로 생성된 SVG 추상 이미지**이며, 이름·학교·작가노트는 모두 지어낸 것입니다.
- **localStorage는 진짜 데이터베이스가 아닙니다.** 찜·장바구니·위탁 등록·주문은 **오직 이 브라우저에만** 저장되며 사이트 데이터를 지우면 사라집니다. 서버도, 공유 상태도 없습니다.
- **실제 결제·계정·개인정보(PII) 없음.** 구매/대여/결제는 전부 **모의 흐름**입니다. 카드 청구도, 배송도, 개인정보 수집·전송도 없습니다.
- **작가 인증 없음.** 데모에서는 누구나 작품을 "등록"할 수 있으며 검수 과정이 없습니다.

**실제 서비스라면** 백엔드 + 실 데이터베이스, 로그인 계정, 실 이미지 호스팅/업로드, 결제
게이트웨이·에스크로, 배송/물류, 작가 신원·저작권 인증, 대여 계약이 추가됩니다. 여기에는
없습니다.

## 기능

- **갤러리** — 매스너리 그리드, 검색 + 필터: **장르**(회화·일러스트·판화·조소), **색감 팔레트**(웜·쿨·파스텔·비비드·모노·어스), **크기**, **구매/대여** 여부. 정렬: 최신·가격·크기·제목순.
- **작품 상세** — 크게 보이는 생성 이미지, 작가노트, 재료, 크기, 팔레트 스와치, **구매/대여 전환**과 **대여 기간 선택**(1·3·6·12개월) + 실시간 합계.
- **작가 프로필** — 소개·학교·작가의 전체 작품 모음.
- **공간 맞춤 추천** — **벽 크기 + 선호 색감 + 용도**(카페/사무실/가정)를 입력하면 투명한 매칭 점수 순으로 작품을 추천합니다.
- **위탁 등록** — 작가가 작품을 "올리는" 폼. **색상 팔레트 + 구성**을 고르면 SVG 미리보기가 실시간 생성되고 localStorage에 저장됩니다.
- **찜/컬렉션**, **장바구니**, **모의 결제**(주문 완료 화면).
- **라이트/다크 테마**, **모바일 우선** 반응형, 드로어 내비게이션, **데모 데이터 초기화** 버튼.

## 절차적 작품 생성 원리

`js/artgen.js`는 작품의 `seed`로 결정론적 PRNG(mulberry32)를 초기화한 뒤 여섯 가지 추상
**구성**(`fields`·`strata`·`orbits`·`grid`·`flow`·`shards`) 중 하나를 작품 팔레트로 그리고
은은한 비네트를 얹습니다. 같은 시드는 항상 같은 이미지를 만들어, 새로고침해도 카드가
그대로 유지됩니다.

## 공간 매칭 원리

`js/recommend.js`는 DOM·스토리지에 의존하지 않는 **순수 함수** 모음으로 각 작품을 채점합니다:

- **크기 적합(50%)** — 벽에 실제로 들어가고 벽의 한계 치수의 약 60%를 차지하면 최고점, 벽보다 크면 0점.
- **색감 일치(30%)** — 팔레트 태그 정확 일치가 최고, 유사 웜/쿨 계열은 부분 점수.
- **용도(20%)** — 카페/사무실/가정별 선호 크기·무드에 가점.

`recommendForSpace()`는 맞지 않는 작품을 제외하고 점수순 정렬 후 개수를 제한합니다. 이
함수들은 `check.mjs`의 **CI 단위 테스트**로 검증됩니다.

## 로컬 실행

설치·빌드 불필요. ES 모듈은 `file://`이 아닌 `http://`가 필요하므로 HTTP로 제공하세요:

```bash
python -m http.server 8992
# http://localhost:8992 접속
```

`npx serve`, VS Code Live Server 등 어떤 정적 서버도 가능합니다.

## 검증

```bash
node check.mjs
```

모든 JSON 파싱, 전 JS `node --check`, `index.html` 필수 컨테이너, 시드 데이터 정합성(전
장르 36점 이상), 공간 매칭 추천기 동작을 확인합니다. CI가 실행하는 것과 동일합니다.

## 기술 & 구조

프레임워크·번들러 없는 순수 **HTML + CSS + ES 모듈 JavaScript**. 상대 경로만 사용.

```
index.html            앱 셸 + 필수 컨테이너
styles.css            모바일 우선, 라이트/다크, 매스너리
js/app.js             SPA 부트스트랩, 해시 라우터, 전 화면
js/artgen.js          시드 기반 절차적 SVG 아트
js/recommend.js       순수 공간 매칭 추천기(단위 테스트)
js/data.js            JSON 로딩 + 필터/정렬 + 위탁작 병합
js/storage.js         localStorage 래퍼(try/catch + 초기화)
js/util.js            포맷팅 + DOM 헬퍼
data/artworks.json    가상 작품 42점
data/artists.json     가상 작가 12명
check.mjs             CI 검증기 + 추천기 단위 테스트
```
